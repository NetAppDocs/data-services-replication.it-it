= Accedi a NetApp Replication
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Utilizzare la NetApp Console per accedere a NetApp Replication.

Per accedere alla Console, puoi utilizzare le tue credenziali del sito di supporto NetApp oppure registrarti per un cloud login NetApp utilizzando il tuo indirizzo email e una password. https://docs.netapp.com/us-en/console-setup-admin/task-logging-in.html["Scopri di più sull'accesso"^].

.Passi
. Apri un browser web e vai su https://console.netapp.com/["NetApp Console"^] .
+
Viene visualizzata la pagina di accesso NetApp Console .

. Accedi alla Console.
. Dal menu di navigazione a sinistra della Console, selezionare *Protezione* > *Replica*.
